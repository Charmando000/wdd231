About This Project

Project Overview

Pixel & Story is a web application created as a final project for WDD 231: Web Frontend Development. This site showcases the integration of HTML, CSS, and JavaScript to create a dynamic, responsive, and user-friendly experience.

The project demonstrates proficiency in:

  • Responsive Web Design (Mobile First)
  • DOM Manipulation and Event Handling
  • Asynchronous JavaScript (Fetch API)
  • Local Storage for User Preferences
  • Accessibility Best Practices
