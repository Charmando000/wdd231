About This Project

Pixel & Story is a web development project showcasing modern web technologies including:

  • Responsive Design: Works seamlessly on mobile, tablet, and desktop devices
  • Dynamic Content: Games displayed dynamically using JavaScript and the Fetch API
  • Local Storage: User preferences saved automatically in the browser
  • Accessibility: WCAG compliant with proper semantic HTML and color contrast
  • Dark Mode: Toggle between light and dark themes with your preference saved
