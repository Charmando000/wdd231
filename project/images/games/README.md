## Image Specifications / Especificaciones

- **Format**: WebP (modern, best compression for web)
- **Aspect Ratio**: 16:9 (landscape orientation)
- **Size**: Already optimized!

## How Images Work / Cómo Funcionan las Imágenes

✅ **Lazy Loading** - Images load only when they come into view (performance boost)
✅ **Responsive** - Images scale automatically to fit any screen size
✅ **Aspect Ratio** - Images maintain 16:9 ratio without distortion
✅ **Fallback** - If aspect-ratio is not supported, images maintain proper height
✅ **Dark Theme** - Background shows while images load
